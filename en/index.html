About

📱 ShuffleBox

v1.1

👋 Hi, I am @Juneix. ShuffleBox is a TikTok-style web player for Emby / Jellyfin. Experience your private media library in a whole new, immersive way. 🎉

All data stays on your device. Free to use.

🔮 Playback

  • Native HTML5 player, best on modern devices.
  • Older devices can use server transcoding.
Device HEVC Decode AV1 Decode
Apple A9 (2015) / M1 A17 Pro (2023) / M3
Android Budget Phones (2016) Budget Phones (2024)
PC Intel 6th-8th Gen iGPU Intel 11th Gen iGPU

🧩 Tips & Tricks

  • Faster Importing: Use "Home Video" library type.
  • Smoother Loading: Limit libraries to < 1,000 videos.
  • Easier Managing: Use multiple libraries and playlists.
  • PWA Support: Add to Home Screen or Install as App. 📲
